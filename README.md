# Learning about interpreters by building one

In my pursuit to understand and contribute to the world of ai/ml infra software such as pytorch (and building my own mini one), I am implementing programming language software. Interpreters are the first step of this path for me.

I am following the course, "Crafting Interpreters". This project implements the first half of the book(written in Java) using C++(also as a way to learn the language).

So far, we can:
 * Read a .x file into memory
 * Parse the tokens: (, ), \[, \], ", "
